# Dé𝐭𝐞𝐫𝐦𝐢𝐧𝐞𝐫 𝐥𝐞 𝐧𝐮𝐦é𝐫𝐨 𝐝𝐞 𝐯𝐞𝐫𝐬𝐢𝐨𝐧 𝐝'𝐮𝐧𝐞 𝐚𝐩𝐩𝐥𝐢𝐜𝐚𝐭𝐢𝐨𝐧

Quand tu fais une mise à jour d'une application ou quand tu regardes si la version de ton appli est compatible avec ton OS, tu as sûrement déjà croisé une série de numéros de ce style :
1.0.0 𝘰𝘶
2.3.13 𝘰𝘶
14.5.9 ...

## 🔢 𝑸𝒖𝒆 𝒔𝒊𝒈𝒏𝒊𝒇𝒊𝒆𝒏𝒕 𝒓é𝒆𝒍𝒍𝒆𝒎𝒆𝒏𝒕 𝒄𝒆𝒔 𝒏𝒖𝒎é𝒓𝒐𝒔 ? 🔢

On appelle cela le 𝒗𝒆𝒓𝒔𝒊𝒐𝒏𝒏𝒂𝒈𝒆 𝒔é𝒎𝒂𝒏𝒕𝒊𝒒𝒖𝒆 (𝐒𝐞𝐦𝐕𝐞𝐫), une méthode claire et universelle pour numéroter tes versions.

Le format 1️⃣.0️⃣.0️⃣ est divisé en trois parties :

- 1️⃣𝑴𝑨𝑱𝑬𝑼𝑹.
- 0️⃣𝑴𝑰𝑵𝑬𝑼𝑹.
- 0️⃣𝑪𝑶𝑹𝑹𝑬𝑪𝑻𝑰𝑭.

### 1️⃣ 𝑴𝑨𝑱𝑬𝑼𝑹 :

Quand tu fais des changements qui cassent la compatibilité avec les versions précédentes.

:::note[👀 𝘌𝘹𝘦𝘮𝘱𝘭𝘦]
Tu réécris une API, ou tu modifies la manière dont les utilisateurs interagissent avec ton application.
:::

### 0️⃣ 𝑴𝑰𝑵𝑬𝑼𝑹 :

Quand tu ajoutes de nouvelles fonctionnalités sans casser ce qui existe déjà.

:::note[👀 𝘌𝘹𝘦𝘮𝘱𝘭𝘦]
Tu intègres un nouveau module ou une option.
:::

### 0️⃣ 𝑪𝑶𝑹𝑹𝑬𝑪𝑻𝑰𝑭 :

Quand tu corriges des bugs ou optimises des fonctionnalités existantes.

:::note[👀 𝘌𝘹𝘦𝘮𝘱𝘭𝘦]
Tu résous un problème de performance ou d'affichage.
:::
